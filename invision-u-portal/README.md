#  InVision U Portal 

Интеллектуальная платформа для автоматизации отбора кандидатов с использованием ИИ-анализа.

##  О проекте
InVision U Portal помогает приемным комиссиям эффективно фильтровать заявки. Система анализирует мотивационные эссе, проверяет их на плагиат и выставляет баллы по компетенциям, экономя до 80% времени проверяющих.

##  Ключевые функции
- **AI Scoring:** Автоматическая оценка эссе по 4 критериям (Лидерство, Профессионализм и др.).
- **Anti-Cheat:** Встроенный детектор коротких и бессмысленных заявок.
- **Admin Dashboard:** Удобный интерфейс для комиссии с просмотром резюме прямо в браузере.
- **Secure Auth:** Разграничение прав доступа для учеников и администраторов.

##  Технологии
- **Framework:** Next.js 14+
- **Database:** SQLite + Prisma ORM
- **Styling:** Tailwind CSS
- **Diagrams:** Mermaid.js

##  Быстрый запуск
1. Установите зависимости: `npm install`
2. Настройте БД: `npx prisma db push` и `npx prisma db seed`
3. Запустите проект: `npm run dev`
